# Rahul - Senior Mechanical & Product Design Engineer Portfolio

A modern, high-performance static developer portfolio designed specifically for **Mechanical Engineering, Product Design, CAD/CAM Modeling, FEA Structural Analysis, and Manufacturing (DFMA)**.

Built strictly as a 100% static web application using **HTML5, Vanilla CSS3, and Vanilla JavaScript (ES6+)**.

## 🛠️ Specialized Mechanical Content

- **CAD & 3D Modeling**: SolidWorks (CSWP), CATIA V5, Autodesk Inventor, Fusion 360
- **FEA & CAE Simulation**: ANSYS Mechanical Structural FEA, ANSYS Fluent CFD, Fatigue & Vibration Analysis
- **Manufacturing & Prototyping**: GD&T (ASME Y14.5), DFMA, Sheet Metal, Injection Molding, CNC Machining, SLA/FDM 3D Printing
- **Featured Projects**:
  1. High-Payload Robotic End-Effector (SolidWorks + Kinematics + SLA 3D Printing)
  2. Aero-Thermal Heat Exchanger (ANSYS Fluent CFD + Thermal Flow Simulation)
  3. Automotive Subframe Structural FEA (ANSYS Mechanical + Topology Optimization)
